WORKFLOW / STEP 01

Open GitHub Codespaces

Start a cloud-hosted development environment and open its integrated terminal.

Action

  • Sign in to GitHub and open an existing repository or create one for the experiment.
  • Open Code → Codespaces → Create codespace on main (the branch name may vary).
  • Wait until the workspace is ready; open Terminal → New Terminal.

বাংলা নোট: নিজের কম্পিউটারে পুরো development environment সেটআপ না করে cloud-based workspace ব্যবহার করছি।

Verify: The editor and terminal are available in the Codespace.

Verify Environment

Inspect the actual instance before quoting its CPU, memory, storage, or operating system.

Run individually or as a block

TERMINAL
pwd
uname -a
cat /etc/os-release
nproc
free -h
df -h /workspaces

What to look for

  • Workspace directory and OS release.
  • CPU core count; total and available memory.
  • Total and available capacity of /workspaces.

Reference from the tested setup: Ubuntu 24.04.5 LTS · 4 cores · 15 GiB total RAM · ~13 GiB available · 32 GB workspace storage · ~19 GB available. These are not live readings or universal Codespaces specifications.

Verify: Read the actual terminal values aloud if they differ.

Configure the Build

Generate a Release configuration in the llama.cpp project directory.

Confirm location and configure

TERMINAL
pwd
cmake -B build -DCMAKE_BUILD_TYPE=Release

Verify: The current path is /workspaces/llama.cpp and CMake finishes configuration without errors.

If configuration fails, inspect the first meaningful error and verify compiler/dependency availability before rerunning it.

06
WORKFLOW / STEP 06

Compile the Project

Compile with four jobs in the tested environment and verify the server executable.

Build and inspect executable

TERMINAL
cmake --build build --config Release -j 4
./build/bin/llama-server --help

Resource-pressure fallback

TERMINAL
cmake --build build --config Release -j 2

Verify: Build completes and the help command displays server options. In the recorded test, the build completed, including llama-server and llama targets.

If the build stops, inspect terminal errors, free -h, disk space and the parallel job count. Do not treat a partial build as success.

07
WORKFLOW / STEP 07

Download and Launch the AI Model

Launch the selected GGUF variant with the exact tested server settings.

Run from /workspaces/llama.cpp

TERMINAL
./build/bin/llama-server \
  --hf-repo Qwen/Qwen2.5-0.5B-Instruct-GGUF:Q4_K_M \
  --host 0.0.0.0 \
  --port 8080 \
  --threads 4
  • --hf-repo: selected model and Q4_K_M variant.
  • --host 0.0.0.0: listen on network interfaces in the environment.
  • --port 8080: browser forwarding port.
  • --threads 4: four configured inference threads.

Verify: Wait for download, model loading, and a server listening message before opening the browser.

The observed model download was about 491 MB. Size, download time, load time and usage may differ. If the repository or variant fails, verify its exact identifier.

WORKFLOW / STEP 11

Stop, Restart and Troubleshoot

Stop only the foreground server process; restart it after returning to the project directory.

Stop safely

Focus the server terminal and press Ctrl + C. This stops the foreground process, not the entire Codespace.

Return to the project

TERMINAL
cd /workspaces/llama.cpp

Launch again

TERMINAL
./build/bin/llama-server \
  --hf-repo Qwen/Qwen2.5-0.5B-Instruct-GGUF:Q4_K_M \
  --host 0.0.0.0 \
  --port 8080 \
  --threads 4

Verify: Wait for model loading and the listening message before reopening browser chat.

If an entire Codespace is stopped and resumed, inspect whether files still exist. A rebuilt, deleted or recreated environment can require restoring or rebuilding files. See Troubleshooting.

Security & port visibility

The server may start without an API key and may report permissive CORS settings. 0.0.0.0 listens on network interfaces in the environment; keep the forwarded port private for this demonstration unless public access is intentionally secured. Running inside Codespaces alone does not make a publicly reachable server safe.
